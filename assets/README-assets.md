# assets/ — where each file goes

| File | Section | Notes |
|---|---|---|
| `header.png` (1280×320) | Top of the README | The profile header. Not the same file as the social preview. |
| `architecture.svg` (1000×248) | How I Think About Systems | Generic layered shape — replaces the ASCII diagram. |
| `stack.svg` (1000×268) | Engineering Stack | Replaces ~24 technology badges with one readable image. |
| `mark.svg` | Footer | The DT monogram, 52px. |
| `avatar.png` (800×800) | **Not in the README** | Upload as your GitHub profile picture. |
| `social-preview.png` (1280×640) | **Not in the README** | Settings → Social preview. This is the card that renders when your profile is shared. |

All files come from the brand kit. Regenerate them with
`system/build_kits.py` and `build_readme_assets.py` if the palette ever changes.
